Explainable AI Framework for Spam SMS Detection Using Transformers
Project Overview

This project develops an Explainable AI framework for spam SMS detection using BERT. The system is designed to automatically classify SMS messages as Spam or Ham and provide an understandable explanation for the prediction.

When a user enters an SMS message, the text is preprocessed and given to a fine-tuned BERT model. The BERT model understands the contextual relationships between words and predicts whether the message is Spam or Ham. SHAP and LIME are then used to identify the important words that influenced the prediction.

The system provides the prediction, confidence score, and human-readable explanation through a simple web-based interface.

System Modules
User Module

Users can:

Enter an SMS message.
Submit the message for analysis.
View the Spam/Ham prediction.
View the confidence score.
View the explanation generated by SHAP and LIME.
Understand which words influenced the prediction.
BERT Classification Module

The BERT module:

Receives the preprocessed SMS text.
Converts the text into tokens using the BERT tokenizer.
Processes the tokens using the Transformer architecture.
Understands the contextual relationship between words.
Predicts whether the SMS is Spam or Ham.
Generates the prediction confidence.
Explainable AI Module

The Explainable AI module uses:

SHAP:

Identifies the contribution of individual words/features toward the prediction.
Shows which words support or oppose the prediction.

LIME:

Provides a local explanation for an individual SMS prediction.
Identifies important words contributing to the classification.
Web Application Module

The web application:

Accepts SMS messages from users.
Sends the message to the trained BERT model.
Displays the prediction.
Displays the confidence score.
Displays the SHAP and LIME explanations.
